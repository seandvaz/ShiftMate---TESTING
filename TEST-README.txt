TEST ENVIRONMENT ONLY — DO NOT UPLOAD TO LIVE.

Changes:
- Home now has Generate Leave Form above Active Settings.
- Home leave generator opens with Start date = today and End date = today.

- Partial book-off leave is included in leave-form date-range totals.
- Existing official PDF leave template/output is preserved.
- Existing v2.1.7 leave sheet/PDF fixes are preserved.
